# Experiment 4 – CNN Architecture Comparison

Comparative study of deep CNN architectures using **Transfer Learning**, with **VGG16 as the main architecture**.

## Dataset

**CIFAR-10**

* Training images: 50,000
* Testing images: 10,000
* Classes: 10
* Image size: 32 × 32 × 3
* Classes: Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck

## Architectures

### Main Architecture

* **VGG16** – Transfer Learning + Fine Tuning

### Comparison Architectures

* **LeNet-5**
* **AlexNet**
* **GoogleNet (Inception)**
* **ResNet50** – Transfer Learning + Fine Tuning

## Techniques Used

* Transfer Learning
* ImageNet Pretrained Weights
* Feature Extraction
* Fine Tuning
* Global Average Pooling
* Dropout
* ReLU Activation
* Softmax Classification
* Inception Modules
* Residual/Skip Connections

## Evaluation

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* Classification Report
* Training Time
* Number of Parameters
